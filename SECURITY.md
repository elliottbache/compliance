# Security Policy

## Supported Versions

Security fixes are provided for the current `1.0.x` release line.

Earlier development releases are not supported for production use.

## Reporting A Vulnerability

Report suspected vulnerabilities through GitHub private vulnerability reporting
if it is enabled for this repository. If private reporting is unavailable,
contact the maintainer at `elliottbache@gmail.com`.

Do not include passwords, API keys, bearer tokens, private certificates, raw
attachment contents, full AI prompts or responses, or unnecessary personal data
in the report. Include enough detail to reproduce the issue safely, such as the
affected endpoint, expected behavior, observed behavior, logs with secrets
redacted, and the release version.

## Production Use

This project provides a production deployment baseline, but it is not a
compliance certification product by itself. Before using it with regulated,
client-confidential, or otherwise sensitive production data, review the
deployment with the responsible organization and define the required security,
privacy, AI data-sharing, backup, retention, monitoring, and incident-response
policies.
